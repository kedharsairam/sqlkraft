Important

By default, SQL Server interprets two-digit years based on a cutoff year of 2049. That

means that SQL Server interprets the two-digit year 49 as 2049 and the two-digit year 50

as 1950. Many client applications, including those based on Automation objects, use a

cutoff year of 2030. SQL Server provides the two digit year cutoff configuration option to

change the cutoff year used by SQL Server. This allows for the consistent treatment of

dates. We recommend specifying four-digit years.
