Additionally, the ISO standard defines a list of reserved keywords. Avoid using ISO reserved

keywords for object names and identifiers. The ODBC reserved keyword list, shown in the

following table, is the same as the ISO reserved keyword list.

Transact-SQL reserved keywords can be used as identifiers or names of databases or database

objects, such as tables, columns, views, and so on. Use either quoted identifiers or delimited

identifiers. Using reserved keywords as the names of variables and stored procedure

parameters is not restricted.
