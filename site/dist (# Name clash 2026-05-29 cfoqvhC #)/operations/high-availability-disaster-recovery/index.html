Description

Site Recovery replicates workloads running on virtual machines or

physical servers so that they remain available in a secondary location

if the primary site isn’t available. You can replicate and fail over SQL

Server virtual machines from on-premises data center to Azure or to

another on-premises data center or from one Azure data centers to

another Azure data center.

Applies to:

Enterprise and Standard editions of SQL Server 2008 R2

(10.50.x) and later versions
