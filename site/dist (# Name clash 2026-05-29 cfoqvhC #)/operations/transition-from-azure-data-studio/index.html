The Azure Data Studio Migration feature in the MSSQL extension for Visual Studio Code helps

you transition from Azure Data Studio to the MSSQL extension by importing existing connections,

connection groups, and settings. This feature ensures a familiar and productive experience when

you move to Visual Studio Code.

Azure Data Studio Migration enables you to:

Import saved database connections and connection groups from Azure Data Studio.

Migrate supported editor and SQL-related settings.

Install Azure Data Studio-style key bindings through the MSSQL Database Management

Keymap companion extension.

  1. Open the Azure Data Studio Migration dialog from the

or from the

changelog notification.

  1. Select or browse to your

.

  1. Choose the items to import:

: Select which connection groups to bring over. Groups keep their

names and color assignments.

: Select individual connections to import. Connections keep server,

database, and authentication metadata.

: Import supported editor and SQL-related settings from

Azure Data Studio.
