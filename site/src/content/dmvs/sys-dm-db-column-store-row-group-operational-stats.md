## Description

SQL Server 2016 (13.x) and later versions SQL database in Microsoft Fabric Returns current row-level I/O, locking, and access method activity for compressed rowgroups length of time a user query must wait to read or write to a compressed rowgroup or partition of a columnstore index, and identify rowgroups that are encountering significant I/O activity or In-memory columnstore indexes don't appear in this DMV.

## Syntax

```sql
sys.dm_db_column_store_row_group_operational_stats
```
