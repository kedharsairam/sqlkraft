## Description

Analytics Platform System (PDW) Returns information about all entries in caches in SQL Server. Use this view to trace cache entries to their associated objects. You can also use this view to obtain statistics on cache Address of the cache. Not nullable. Name of the cache. Not nullable. Address of the descriptor of the cache entry. Not nullable. Address of the user data in the cache entry. 0x00000000 = Entry data address isn't available.

## Syntax

```sql
context_switches_count
```
