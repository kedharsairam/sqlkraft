## Description

Analytics Platform System (PDW) Returns the status of each hand for a specific cache clock. Address of the cache associated with the clock. Is not Name of the cache. Is not nullable. Type of cache store. There can be several caches of the Type of hand. Value is one of the following: Status of the clock. Value is one of the following: Number of sweeps made through the cache to remove Number of entries removed by all sweeps. Is not nullable.
