## Description

Analytics Platform System (PDW) Returns a row for each pending I/O request in SQL Server. Memory address of the IO request. Is not nullable. Type of pending I/O request. Is not nullable. Internal use only. Is not nullable. Indicates whether the I/O request is pending (1) or has been completed by the operating system (0).
