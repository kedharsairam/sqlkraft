Name

INIT_NOLOCKSPACE

Message

Text

Not enough memory for the configured number of locks. Attempting to start with a

smaller lock hash table, which may impact performance. Contact the database

administrator to configure more memory for this instance of the Database Engine.

Not enough memory for the desired lock manager hash table size. An attempt will be made to

allocate a smaller hash table.

Check server memory configuration parameters (min/max server memory), check for memory

pressures. Provide SQL Server more memory.
