Name

LDDB_MASTER_LOAD_FAILED

Message

Text

Failed to restore master database. Shutting down SQL Server. Check the error logs, and

rebuild the master database. For more information about how to rebuild the master

database, see SQL Server Books Online.

This is a general error message indicating various problems with the

database.

Check the error logs for more information. To create a usable

database, run Setup.exe

with the REBUILDDATABASE option. For more information see "How to: Install SQL Server from

the Command Prompt" in SQL Server Books Online.
