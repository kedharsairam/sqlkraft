Message

Text

During undoing of a logged operation in database '%.\*ls', an error occurred at log record

ID %S_LSN. Typically, the specific failure is logged previously as an error in the Windows

Event Log service. Restore the database or file from a backup, or repair the database.

This error is a rollup error for undo recovery. This error indicates that SQL Server has placed the

database into the SUSPECT state when it fails to roll back uncommitted transactions from

database (undo). The transaction log file, the primary filegroup, and possibly other filegroups,

may be damaged. The database failed recovery during startup of SQL Server and is therefore

unavailable. You must take action to resolve the problem.

If this error occurs for

, the SQL Server instance shuts down.

This error may appear with other errors in the SQL Server error log. Examples of such errors

include

9001

,

823

,

824

,

17204

(shows OS error when accessing a file),

17053

(shows OS error).

These last two errors may provide insight into the underlying reason for I/O failures.
