Message

Text

Failed to open the Windows Server Failover Clustering registry subkey '%.*ls' (Error code

%d). The parent key is the cluster root key. The WSFC service may not be running or may

not be accessible in its current state, or the specified arguments are invalid. If the

corresponding availability group has been dropped, this error is expected. For information

about this error code, see "System Error Codes" in the Windows Development

documentation.

If a WSFC cluster is destroyed, it removes all registry keys related to Always On availability

groups.

After re-creating a WSFC cluster, disable and then re-enable Always On on every cluster node

on which an instance of SQL Server is enabled for Always On. You can use the SQL Server

Configuration Manager for this task.
