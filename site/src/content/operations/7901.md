DBCC2_DATABASE_IN_EMERGENCY_MODE

Message Text

The repair statement was not processed. This level of repair is not supported when the

database is in emergency mode.

The database is in emergency mode and a repair level other than REPAIR_ALLOW_DATA_LOSS

has been specified. Repairs cannot be made in emergency mode unless

REPAIR_ALLOW_DATA_LOSS is specified.

Rerun the command and specify the REPAIR_ALLOW_DATA_LOSS option.
