Message Text

The sp_estimate_data_compression_savings stored procedure cannot be used for

temporary tables.

A temporary table was used as an argument for the sp_estimate_data_compression_savings

stored procedure. Although the compression of temporary tables is supported, you cannot use

sp_estimate_data_compression_savings to estimate the compression savings.

Remove the temporary table as an argument for sp_estimate_data_compression_savings.
