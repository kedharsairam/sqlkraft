This article describes how to search for a specific value or data column in the trace output

while the trace is running by using SQL Server Profiler.

1. Select any row in the trace results while the trace is running.

2. On the

menu, select.

3. In the

dialog box, enter a search value in the

text box and optionally

specify a data column.

4. To find the next occurrence of a value, select.

5. To find the previous occurrence of a value, select.

The search starts at the row you selected in Step 1.
