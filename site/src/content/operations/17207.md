%ls: Operating system error %ls occurred while creating or opening file '%ls'. Diagnose

and correct the operating system error, and retry the operation.

SQL Server was unable to open the specified file because of the specified OS error.

You may see error 17207 in the Windows Application Event or the SQL Server Error log when

SQL Server cannot open a database and/or transaction log files. Here is an example of what the

error may look like.
