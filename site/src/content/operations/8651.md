Message Text

Could not perform the requested operation because the minimum query memory is not

available. Decrease the configured value for the 'min memory per query' server

configuration option.

Other processes are consuming server memory (exerting memory pressure in the server).

Either decrease the configured value for the min memory per query' server configuration

option or reduce the query load to the server.

The following list outlines general steps that will help in troubleshooting memory errors:

1. Verify whether other applications or services are consuming memory on this server.

Reconfigure less critical applications or services to consume less memory.

2. Start collecting performance monitor counters for

: Buffer Manager
