SQL Server Assertion: File: <%s>, line = %d Failed Assertion = '%s' %s. This error may be

timing-related. If the error persists after rerunning the statement, use DBCC CHECKDB to

check the database for structural integrity, or restart the server to ensure in-memory data

structures are not corrupted.

This error can be caused by transient, timing-related errors, or by in-memory or on-disk data

corruption.

Rerun the statement that caused the exception to fire. If the error was caused by a timing-

related event, the error may not recur. If the problem persists, run DBCC CHECKDB to check for

on-disk corruption. Restart the server to ensure the in-memory data structures are not

corrupted.
