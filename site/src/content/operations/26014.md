SNI_SSL_USER_CERT_FAILURE

Message

Text

Unable to load user-specified certificate [Cert Hash(sha1) "%hs"]. The server will not

accept a connection. You should verify that the certificate is correctly installed. See

"Configuring Certificate for Use by SSL" in Books Online.

attempted to load the certificate named in the message but the operation failed.

This problem must be resolved before SQL Server can use this certificate.

Possible causes of the error include:

The certificate could have been moved or deleted.

If the login used by SQL Server has changed, SQL Server may not have permission to

access the certificate.

The certificate may have expired.
