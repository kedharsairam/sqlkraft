Product Name

Event ID

556

Event Source

MSSQLSERVER

Component

SQLEngine

Symbolic

Name

WRONGPAGE

Message Text

INSERT EXEC failed because the stored procedure altered the schema of the target

table.

Query store is on.

The plan is removed after the Query Store fills up.

Increase the size of the Query Store.

Clear the procedure cache when Query Store comes back from READ WRITE state

Recompile just the INSERT EXEC statement to force it to go through the regular compile path

and avoid hitting this exception due to unplanned recompilation caused by plan missing in

Query Store.

For more information, see our

troubleshooting article on error 556.
