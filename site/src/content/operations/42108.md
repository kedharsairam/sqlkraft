Message Text

Can not connect to the SQL pool since it is paused. Please resume the SQL pool and try

again.

Synapse SQL pool is in status called Paused and needs to be resumed before retrying

connection to the pool. This error requires action from the user.

Resume a SQL pool and retry connecting to the Synapse SQL pool.
