Message

Text

The log shipping primary database %s.%s has backup threshold of %d minutes and has

not performed a backup log operation for %d minutes. Check agent log and logshipping

monitor information.

Log shipping is out of synchronization beyond the backup threshold. The backup threshold is

the number of minutes that are allowed to elapse between log-shipping backup jobs before an

alert is generated. This message does not necessarily indicate a problem with log shipping.

Instead, this message might indicate one of the following problems:

The backup job is not running. Possible causes for this include the following: the SQL

Server Agent service on the primary server instance is not running, the job is disabled, or

the job's schedule has been changed.

The backup job is failing. Possible causes for this include the following: the backup folder

path is not valid, the disk is full, or any other reason that the BACKUP statement could fail.
