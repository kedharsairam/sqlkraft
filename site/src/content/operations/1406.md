DBM_BADSTATEFORFORCESERVICE

Message Text

Unable to force service safely. Remove database mirroring and recover database "%.*ls"

to gain access.

The SQL Server Database Engine cannot force service because the mirroring state cannot

guarantee that the force service process would work correctly.

Remove database mirroring. You can then recover the mirror database to gain access to it.
