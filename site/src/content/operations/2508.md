DBCC_OUT_OF_DATE_PAGE_OR_ROW_COUNT

Message Text

The %.*ls count for object "%.*ls", index ID %d, partition ID %I64d, alloc unit ID %I64d

(type %.\*ls) is incorrect. Run DBCC UPDATEUSAGE.

In versions of SQL Server before SQL Server 2005 (9.x), the values for the table and index row

counts and page counts can become incorrect. Databases that were created on versions prior

to SQL Server 2005 (9.x) may contain incorrect counts. DBCC CHECKDB has been enhanced to

detect these errors and returns this warning message when the error encountered.

Run DBCC UPDATEUSAGE against the specified object or index, or against the database in

which the object is contained to correct the invalid counts.
