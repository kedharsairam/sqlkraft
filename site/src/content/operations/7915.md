Message Text

Repair: IAM chain for object ID O_ID, index ID I_ID, partition ID PN_ID, alloc unit ID A_ID

(type TYPE), has been truncated before page P_ID and will be rebuilt.

This is an information message sent by REPAIR that indicates that the specified Index Allocation

Map (IAM) chain was patched so that it could be rebuilt. This patching may have required the

allocation of a new head of the IAM chain or the removal of bad pages from the chain.
