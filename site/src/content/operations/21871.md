Symbolic Name

SQLErrorNum21871

Message Text

Publisher %s of database %s has not been redirected.

checks the table MSredirected_publishers in the

distribution database for an entry for the identified publisher and publisher database.

returns error 21871 when no entry is found.

is only relevant for redirected publishers. If the

publisher database is a member of an availability group, use the stored procedure

to associate the publisher and publisher database with the Availability

Group Listener Name of the availability group.
