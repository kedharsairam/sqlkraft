An error has occurred while establishing a connection to the server. When connecting to

, this failure may be caused by the fact that under the default settings SQL

Server does not allow remote connections. (provider: TCP Provider, error: 0 - No

connection could be made because the target machine actively refused it.) (Microsoft SQL

Server, Error: 10061)

The server did not respond to the client request. This error could occur because the server is

not started.

Make sure that the server is started.
