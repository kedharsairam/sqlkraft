Component

Symbolic Name

INIT_NOBUFSPACE

Message Text

initdata: No memory for kernel buffers.

The buffer pool's initial memory allocations or reservations have failed, and SQL Server exits.

Usually caused by starting SQL Server on an extremely small machine - far smaller than the

minimum system requirements.
