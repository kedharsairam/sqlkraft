HK_UNSUPPORTED_IDENTITY_TABLE_VAR

Message

Text

Using a memory optimized table type that uses the IDENTITY property with any of its

columns is not supported when using the type outside the context of a natively compiled

stored procedure.

Do not use a memory-optimized table type that uses the identity property with any of its

columns.
