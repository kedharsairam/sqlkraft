Symbolic Name

DBCC_DATABASE_IN_READ_ONLY_MODE

Message Text

The repair statement was not processed. The database cannot be in read-only mode.

This message indicates that the database is in read-only mode. Repairs are not possible when a

database is in read-only mode.

Set the database to read-write by using ALTER DATABASE, and then re-run the DBCC

command.

ALTER DATABASE (Transact-SQL)
