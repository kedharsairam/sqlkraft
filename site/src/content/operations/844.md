BUFLATCH_TIMEOUT_CONTINUE

Message

Text

Time out occurred while waiting for buffer latch -- type %d, bp %p, page %d:%d, stat %#x,

database id: %d, allocation unit id: %I64d%ls, task 0x%p : %d, waittime %d seconds, flags

0x%I64x, owning task 0x%p. Continuing to wait. %ls

A SQL process is waiting to acquire a latch. This problem can be caused by an I/O operation

taking too long to complete. Typically this type of error is the result of other tasks blocking

system processes. In some cases, this error might be caused by hardware failure. When this

error message occurs, you might notice that the computer, and SQL Server, stop responding.

This error message is dependent on the overall environment of your system. Any of the

following circumstances might lead to an overstressed system:

Hardware that doesn't meet your input/output (I/O) and memory needs

Improperly configured and tested settings

Inefficient design
