Event ID

10003

Event Source

MSSQLSERVER

Component

SQLEngine

Symbolic Name

HR_E_OUTOFMEMORY

Message Text

The provider ran out of memory.

Low system memory has caused the OLE DB provider to run out of memory.

Restart the instance of SQL Server. If that does not help, restart the computer. If the problem

persists, collect OLE DB trace events using SQL Server Profiler and provide this data to product

support for the OLE DB provider.

SQL Server Profiler Templates and Permissions

SQL Server Native Client (OLE DB)
