Azure Arc automatically installs the Azure extension for SQL Server when a server connected to

Azure Arc has SQL Server installed. All the SQL Server instance resources are automatically

created in Azure, providing a centralized management platform for all your SQL Server

instances.

To automatically connect your server, see

Azure Connected Machine agent deployment

options.

If your server is already connected to Azure, but Azure extension for SQL Server didn't deploy

automatically.

The following table highlights each method so that you can determine which works best for

your deployment. For detailed information, follow the links to view the steps for each topic.

Description

Interactively

Manually connect the SQL Server on a single physical or virtual machine that is already

connected to Azure Arc.

Connect your SQL Server to Azure Arc on a server already enabled

by Azure Arc

At scale

Manage automatic connection for SQL Server enabled by Azure Arc

At scale

Connect machines at scale by running PowerShell scripts with Configuration Manager

At scale

Connect machines at scale with a Configuration Manager custom task sequence
