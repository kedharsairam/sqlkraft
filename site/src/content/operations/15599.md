Symbolic Name

SEC_LOCAL_TEMP_AUDIT_PERMISSIONS

Message Text

Auditing and permissions can't be set on local temporary objects.

Auditing and permissions do not have any effect when set for local or global temp objects. The

statements do not result in an error (the operations will return success), but have no effect.

This behavior has not changed, however beginning with SQL Server 2012 (11.x), this

informational message alerts the user.

No action is necessary, but consider removing statements that attempt to set auditing or

permissions on local or global temp objects.
