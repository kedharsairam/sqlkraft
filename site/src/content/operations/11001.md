Text

An error has occurred while establishing a connection to the server. When connecting to

, this failure may be caused by the fact that under the default settings SQL

Server does not allow remote connections. (provider: TCP Provider, error: 0 - No such host

is known.) (.Net SqlClient Data Provider)

The SQL Server client cannot connect to the server. The error could occur because either the

client cannot resolve the name of the server or the name of the server is incorrect.

Make sure that you have entered the correct server name on the client, and that you can

resolve the name of the server from the client. To check TCP/IP name resolution, you can use

the

command in the Windows operating system.
