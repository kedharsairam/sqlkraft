Message Text

The model of the processor on the system does not support creating

construct. This error

typically occurs with older processors.

Memory-optimized tables require a processor model that supports atomic compare-and-

exchange operations on 128-bit values, which require the assembly instruction CMPXCHG16B.

Certain older AMD processor models do not support the CMPXCHG16B instruction. Also,

certain virtualization environments do not enable this instruction by default.

Upgrade your processor. If your processor supports the instruction and you are running SQL

Server in a virtual machine, change the configuration to support the instruction CMPXCHG16B.
