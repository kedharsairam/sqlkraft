BPOOL_SCAN_LONG_DURATION

Message

Text

Certain operations in Microsoft SQL Server trigger a scan of the buffer pool (the cache that

stores database pages in memory). On systems that have a large amount of RAM (1 TB of

memory or greater), scanning the buffer pool may take a long time. This slows down the

operation that triggered the scan.

This is an informational message, no action is necessary.

This message can be suppressed by TF890. For more information, see

TF890.
