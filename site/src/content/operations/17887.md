Message Text

IO Completion Listener (0x%lx) Worker 0x%p appears to be non-yielding on Node %ld.

Approx CPU Used: kernel %I64d ms, user %I64d ms, Interval: %I64d.

Indicates that there is a possible problem with the I/O Completion Port Listener on the

specified node when executing the I/O Completion routine for a network read/write event. This

error will go away when the I/O Completion Port Listener returns from executing the I/O

Completion routine.

Contact Microsoft Customer Support Services (CSS).
