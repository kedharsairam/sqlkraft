The server was unable to load the SSL provider library needed to log in; the connection

has been closed. SSL is used to encrypt either the login sequence or all communications,

depending on how the administrator has configured the server. See Books Online for

information on this error message: 0xXXXX. [CLIENT: 11.11.11.11]

This error indicates that the client has closed the connection. This error could occur because

the connection time-out has expired. The error message displays a value from the operating

system that describes the underlying problem.

If the error code in the message is 0x2746 (decimal value 10054), this means that the

connection was reset by the client, typically because of a time-out. To resolve the error,

increase the connection time-out on the client or calling program.

To determine a possible solution for other error message values, use the operating system

command

and specify the decimal value of the error code.
