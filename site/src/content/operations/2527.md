DBCC_INDEX_FILEGROUP_IS_OFFLINE

Message Text

Unable to process index I_NAME of table O_NAME because filegroup F_NAME is offline.

This informational message indicates that the index cannot be checked because one of the

filegroups that stores data for the index is offline. The state of the files in a filegroup

determines the availability of the whole filegroup. For a filegroup to be available, all files within

the filegroup must be online. If there are no other problems, all other indexes of the same

object will be checked.

To view the state of the files for the specified filegroup, query either the

or

catalog view.

Restore the offline file from a backup.
