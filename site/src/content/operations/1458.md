Message

Text

The principal copy of the '%.\*ls' database encountered error %d, status %d, severity %d.

Database mirroring has been suspended. Try to resolve the error condition, and resume

mirroring.

This messages indicates that the principal database encountered an error that caused database

mirroring to be suspended.

Most cases of this error are self correcting. If the problem persists, restarting the database or

server instance typically corrects the problem. For more information, look in the SQL Server

error log on each partner for the associated error that preceded this message.
