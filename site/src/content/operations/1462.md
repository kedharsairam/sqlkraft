Symbolic Name

DBM_DISABLED_DUE_TO_FAILED_REDO

Message Text

Database mirroring is disabled due to a failed redo operation. Unable to resume.

Database mirroring failed to redo a log record on the mirror.

The most likely cause is that an add-file operation completed on the principal database but

then failed on the mirror database because file names or directory structures differ on the

principal server and mirror server.

Look in the SQL Server error log for the cause of this error. Try to resolve the cause and resume

mirroring on the database.
