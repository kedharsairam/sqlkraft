Symbolic

Name

FS_MINIVER_OVERFLOW

Message Text

The total number of versions for a single file has reached the maximum limit set by the

file system.

In multiple active result sets (MARS) or trigger scenarios, SQL Server uses the miniversion

specified by the operating system.

Try to avoid repeated updates to the data in the same transaction.
