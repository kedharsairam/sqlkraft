SQL Server could not spawn %s thread. Check the SQL Server error log and the operating

system error log for information about possible related problems.

created. Examples of background tasks include Checkpoint, Lazy Writer, Database Recovery

task, Log Reader, Log Writer, Auto shrink task, Communication manager, Parallel Redo worker
