06/06/2025

Applies to:

SQL Server

Azure SQL Managed Instance

You can run SQL Server Profiler in several different ways, to support gathering trace output in

various scenarios. You can start SQL Server Profiler from the Windows

menu, from the

menu in Database Engine Tuning Advisor, and from several locations in SQL Server

Management Studio.

When you first start SQL Server Profiler and select

from the

menu, the

application displays a

dialog box where you can specify a SQL Server

instance to connect to.

The following sections describe the ways to start SQL Server Profiler.

Select the Windows

icon or press the Windows key and start to type "SQL Server Profiler

18", or a later version as appropriate. When the

SQL Server Profiler 18

tile appears, select it.

On the Database Engine Tuning Advisor

menu, select

SQL Server Profiler

.

You can start SQL Server Profiler from several locations in SQL Server Management Studio.

When SQL Server Profiler starts, it loads the connection context, trace template, and filter

context of its launch point. SQL Server Management Studio starts each SQL Server Profiler

session in its own instance, and Profiler continues to run if you shut down SQL Server

Management Studio.

In the SQL Server Management Studio

menu, select

SQL Server Profiler

.
