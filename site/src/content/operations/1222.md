Event Source

MSSQLSERVER

Component

SQLEngine

Symbolic Name

LK_TIMEOUT

Message Text

Lock request time out period exceeded.

Another transaction held a lock on a required resource longer than this query could wait for it.

Perform the following tasks to alleviate the problem:

1. Locate the transaction that is holding the lock on the required resource, if possible. Use

and

dynamic management views.

2. If the transaction is still holding the lock, terminate that transaction if appropriate.

3. Execute the query again.

If this error occurs frequently change the lock time-out period or modify the offending

transactions so that they hold the lock for less time.
