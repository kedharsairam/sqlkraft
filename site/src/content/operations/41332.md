SQL_SNAPSHOT_NOT_SUPPORTED

Message

Text

Memory optimized tables and natively compiled stored procedures cannot be accessed or

created when the session TRANSACTION ISOLATION LEVEL is set to SNAPSHOT.

The transaction was started in snapshot isolation level and then attempted to use an

incompatible feature.

Start the transaction with a different isolation level. For more information, see

In-Memory OLTP

(In-Memory Optimization).
