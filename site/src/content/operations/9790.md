SB3_XMIT_ERROR_ENTRANCE_BROKER_SINGLE_USER

Message Text

Unable to route the incoming message. The system database MSDB containing routing

information is in SINGLE USER mode.

An error occurred while trying to classify a message received off the wire because the MSDB

database was in Single User mode.

Change MSDB to be in MULTI USER mode with the ALTER DATABASE command.
