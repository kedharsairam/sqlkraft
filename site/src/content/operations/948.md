Message Text

The database '%.\*ls' cannot be opened because it is version %d. This server supports

version %d and earlier. A downgrade path is not supported.

Certain features in SQL Server affect the structure of the database files. When you attach a

database to another instance of SQL Server, the file format might not be compatible with a

different version of the Database Engine.

For example, this error can be caused by using the vardecimal storage format in a later version

of SQL Server and then trying to attach the database files in a version earlier than SQL Server

2005 (9.x) Service Pack 2.
