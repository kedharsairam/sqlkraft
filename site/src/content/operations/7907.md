Message Text

Table error: The directory 'DIRECTORY' in partition ID PN_ID is not a valid Filestream

directory.

The name of a column directory is the relational engine column ID of the partition. If a column

directory name cannot be converted to a column ID, the directory is not a valid column

directory.

Run hardware diagnostics and correct any problems. Also examine the Microsoft Windows

system and application logs and the SQL Server error log to see whether the error occurred as

the result of hardware failure. Fix any hardware-related problems that are contained in the logs.
