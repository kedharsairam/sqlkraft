Name

DEMO_SYSCATUPDATE

Message Text

System table ID %d has been updated directly in database ID %d and cache coherence

may not have been maintained.

should be restarted.

This error indicates that a system object was updated directly. Manually updating system tables

is not supported. The system tables should only be updated by the SQL Server database

engine. When SQL Server detects user initiated changes to the system tables, error 17659 is

raised. An event that resembles the following is logged in the SQL Server Error Log or in the

Application log in Event Viewer in this scenario.

Log Name: Application

Source: MSSQLServer

Event ID: 17659

Task Category: Server

Level: Information

Description: Warning: System table ID %d has been updated directly in database ID %d and

cache coherence may not have been maintained. SQL Server should be restarted.
