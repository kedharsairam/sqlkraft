This article describes how to view filters on data columns for event classes by using SQL Server

Profiler.

1. Open a trace file, trace table, or SQL script, and on the

menu, select

. If

you're editing a trace template or creating a new trace, skip this step.

2. On the

tab, right-click the data column name for the filter you want to

view, and select

.

3. In the

dialog box, expand the filter comparison operators to see the assigned

value for the specified criterion. Repeat Steps 2 and 3 for all columns for which you want

to view filter information.

Comparison operators with assigned values are formatted bold.
