Message

Text

The full path length of the Local Database instance folder is longer than MAX_PATH. The

instance must be stored in folder: %%LOCALAPPDATA%%\Microsoft\Microsoft SQL Server

Local DB\Instances\<instance name>.

The path where the instance should be stored is longer than MAX_PATH.

Create a new path that is shorter than MAX_PATH.
