## Description

Contains one row for each index and table in the current database. XML indexes are not supported in this view. Partitioned tables and indexes are not fully supported in this view; use ID of the table to which the index belongs. Identified for informational purposes only. Not supported. Future compatibility is not guaranteed. Pointer to the first or root page.
