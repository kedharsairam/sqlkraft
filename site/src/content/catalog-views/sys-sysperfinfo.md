## Description

Contains a Microsoft SQL Server Database Engine representation of the internal performance counters that can be displayed through the Windows System Monitor. Performance object name, such as Name of the performance counter within the object, such as Named instance of the counter. For example, there are counters maintained for each type of lock, such as instance name distinguishes between similar counters.
