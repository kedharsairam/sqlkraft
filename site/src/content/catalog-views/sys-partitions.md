## Description

Analytics Platform System (PDW) SQL database in Microsoft Fabric Contains a row for each partition of all the tables and most types of indexes in the database. Special index types such as Full-Text, Spatial, and XML aren't included in this view. All tables and indexes in SQL Server contain at least one partition, whether or not they are explicitly Indicates the partition ID. Unique within a database.
