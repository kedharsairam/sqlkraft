## Description
The referential action that was declared for this

FOREIGN KEY when an update happens.

0 = No action

1 = Cascade

2 = Set null

3 = Set default


## Description of the referential action that was
declared for this FOREIGN KEY when an update

happens:

NO_ACTION

CASCADE

SET_NULL

SET_DEFAULT

1 = Name was generated by the system.

0 = Name was supplied by the user.
