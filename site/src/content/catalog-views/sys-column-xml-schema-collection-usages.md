## Description

Returns a row for each column that is validated by an XML schema. The ID of the object to which this column belongs. The ID of the column.

## Permissions

Article • 02/28/2023 Description The ID of the object to which this column belongs. The ID of the column. Is unique within the object. The ID of the collection that contains the validating XML schema namespace of the column.
