## Description

Returns a row for each availability group where the local instance of SQL Server hosts an availability replica. Each row contains a cached copy of the availability group metadata. Unique identifier (GUID) of the Name of the availability group. This is a user-specified name that must be unique within the Windows Server Resource ID for the WSFC cluster Resource Group ID for the WSFC User-defined failure condition level

## Syntax

`failure_condition_level`
