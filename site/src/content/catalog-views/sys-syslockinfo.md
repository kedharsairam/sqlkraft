## Description

Contains information about all granted, converting, and waiting lock requests. Textual description of a lock resource. Contains a part of the Binary lock resource. Contains the actual lock resource that is contained in the lock manager. This column is included for tools that know about the lock resource format for generating their own formatted lock resource, and for performing self Lock value block.
