## Description

Creates a collection item in a user-defined collection set. A collection item defines the data to be collected and the frequency with which the data is collected. Transact-SQL syntax conventions The unique local identifier for the collection set. The GUID that identifies the collector type to use for this item. , with no default. For a list of collector types, query the The name of the collection item.
