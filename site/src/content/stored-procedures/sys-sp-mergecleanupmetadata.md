## Description

Should only be used in replication topologies that include servers running versions of SQL Server before SQL Server 2000 (8.x) Service Pack 1. administrators to clean up metadata in the system tables. This stored procedure is executed at the Publisher on the Transact-SQL syntax conventions metadata for all publications. The publication must already exist if explicitly specified. Specifies whether to reinitialize the Subscriber.

## Syntax

`sp_mergecleanupmetadata`
