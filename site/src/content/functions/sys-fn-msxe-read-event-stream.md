## Description

returns binary data for internal use by the.NET class. Extended Events UI in the SQL Server Management Studio (SSMS) uses this class to read event session data. To view human-readable event data, use one of the following instead of calling sys.fn_xe_file_target_read_file The specific source of event data returned by the function.
